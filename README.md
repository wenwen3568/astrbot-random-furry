# 🐾 AstrBot 随机兽图插件

从 [furry.axzt.top](https://furry.axzt.top) 获取随机福瑞图片，并自动保存到指定目录。

## ✨ 功能

- 群聊指令 `/随机兽图` 获取一张随机福瑞图片
- 支持直接发送图片到群聊

## 📦 安装

1. 在 AstrBot 管理后台 → 插件市场 → 搜索随机兽图。
2. 点击安装
3. 启用插件。

## 🔧 配置

如需修改图片保存路径，请编辑 `main.py` 中的 `self.save_dir` 变量。

## 📄 依赖

- aiohttp（通常 AstrBot 已自带）
